# Reprieve Frontend

The web client for Reprieve is built with:
- **Next.js 16** (App Router)
- **Tailwind CSS** + **Framer Motion**
- **2D / 3D Graph Visualization Canvas** (Force-directed graph layout with pulsing risk halos)
- **Clerk Authentication**

The application provides:
1. Executive Risk Dashboard & Compound Risk Scoring.
2. Force-directed Graph Canvas showing living microservice dependencies.
3. Autonomous Risk Alerts & Shortest Proof Path Animations.
4. Steward AI Copilot Drawer (Streaming SSE).
