# Dataset Specifications

This directory contains benchmark topologies and evaluation seed bundles for Reprieve.

## Seed Topology: Northwind Pay
A synthetic financial services topology comprising:
- **25 Microservices** across Tiers 1–3
- **8 Engineering Teams** and 40+ People
- **4 Customer-Facing Journeys** (e.g., Checkout, Merchant Payouts)
- **12 Controls & Compensating Safeguards** (PCI-DSS, SOC2, Encryption)
- **42 Planted Risk Scenarios** for invariant rule testing

The gold-standard dataset will be placed in `data/seed/northwind.json`.
